# 메이플스토리 파티 분배 디스코드 봇

**ConnectLabs · oh_nightmare · 2025**

메이플스토리 파티 플레이 후 아이템 판매금을 파티원에게 공평하게 분배하는 디스코드 슬래시 커맨드 봇.
**카르마의 가위 비용**과 **누진 방식 택배 수수료**를 자동 차감하여 1인당 최종 수령액을 임베드로 출력합니다.

---

## 슬래시 명령

### `/분배`

| 옵션 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `아이템명` | String | ✅ | 판매한 아이템 이름 (자유 입력) |
| `판매금` | Integer | ✅ | 거래소 수수료 **제외 후** 실수령 메소 |
| `파티원수` | Integer (1~15) | ✅ | 분배할 파티 인원 수 |
| `카르마가위` | Integer | ❌ | 카르마의 가위 구매 비용 (없으면 생략) |

### 사용 예시

```
/분배 아이템명:이계의반지 판매금:50000000 파티원수:6 카르마가위:1500000
```

---

## 처리 순서

```
1) 판매금 − 카르마의 가위              = 정산 금액
2) 정산 금액 ÷ 파티원수 (버림)         = 1인당 몫
3) 1인당 몫 → 누진 택배 수수료        (구간별 누진 내역 표시)
4) 분배자(본인)는 1인당 몫 그대로 수령 — 수수료 X
   다른 파티원 (N-1명)만 택배 발송 → 각자 (1인당 몫 − 수수료) 수령
   분배자 부담 총 택배 수수료 = 수수료 × (N-1)
```

> **분배자 = 명령을 실행한 사용자**. 본인 몫은 인벤토리에서 바로 챙기므로 택배가 필요 없고, 따라서 수수료도 부과되지 않습니다.

---

## 택배 수수료 (누진 방식)

소득세처럼 **각 구간 초과분에만** 해당 요율을 적용합니다. 전체 금액에 단일 요율을 곱하는 방식이 **아닙니다**.

```
총 수수료 = 10,000(기본료) + Σ (구간 초과분 × 구간 요율)
```

### 구간별 요율표

| 구간 | 요율 |
|------|------|
| 0 ~ 10만 | 0% |
| 10만 ~ 100만 | 0.8% |
| 100만 ~ 500만 | 1.8% |
| 500만 ~ 1,000만 | 3.0% |
| 1,000만 ~ 2,500만 | 4.0% |
| 2,500만 ~ 1억 | 5.0% |
| 1억 초과 | 6.0% |

### 검증된 계산 예시

| 1인당 몫 | 누진 산출 | 기본료 | 합계 |
|---------|-----------|------|------|
| 1,000,000 | 900,000×0.8% = 7,200 | 10,000 | **17,200** |
| 1,200,000 | 7,200 + 200,000×1.8%(3,600) | 10,000 | **20,800** |
| 5,500,000 | 7,200 + 72,000 + 500,000×3%(15,000) | 10,000 | **104,200** |
| 100,000,000 | 7,200 + 72,000 + 150,000 + 600,000 + 75,000,000×5% | 10,000 | **4,589,200** |

## 💡 분할 송금 절약 팁 (자동 추천)

1인당 몫이 클 때, 여러 번 나눠서 송금하면 누진 구간이 낮아져 수수료를 아낄 수 있습니다. 봇이 자동으로 2~10회 분할을 시뮬레이션해서 절약액이 가장 큰 횟수를 추천합니다.

**예시 — 550만 메소 송금**
- 단일 송금: `104,200메소`
- 5회 균등 분할 (110만씩): `19,000 × 5 = 95,000메소`
- **절약: 9,200메소** ✓

**예시 — 1인당 8,083,333메소 (이계의반지 5천만, 6명, 가위 150만)**
- 단일 송금: `181,699메소`
- 8회 분할 추천 → `약 42,603메소 절약`

```

정산 금액 : 48,500,000메소

💡 절약 팁: 각 파티원에게 8회 분할 송금 시 1명당 ≈42,603메소 절약 (총 ≈213,015메소)
```

## 배포 (요약)

1. 디스코드 개발자 포털 → Application 생성 → Bot 토큰 발급
2. OAuth2 → URL Generator → SCOPES `bot` + `applications.commands`, BOT PERMISSIONS `Send Messages` + `Embed Links` → 서버 초대
3. GitHub 레포에 푸시 (`.env` 절대 금지)
4. Railway → New Project → Deploy from GitHub repo → 레포 선택
5. Variables → `DISCORD_BOT_TOKEN` 등록
6. Deployments 로그에서 `로그인 성공 ... 슬래시 명령어 1개 동기화 완료` 확인
