# 메이플스토리 파티 분배 디스코드 봇

**ConnectLabs · oh_nightmare · 2025**

메이플스토리 파티 플레이 후 아이템 판매금을 파티원에게 공평하게 분배하는 디스코드 슬래시 커맨드 봇.
**카르마의 가위** 비용과 **택배 수수료**를 자동 차감하여 1인당 최종 수령액(=택배로 발송할 금액)을 임베드로 출력합니다.

---

## 슬래시 명령

### `/분배`

| 옵션 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `아이템명` | String | ✅ | 판매한 아이템 이름 (자유 입력) |
| `판매금` | Integer | ✅ | 거래소 수수료 **제외 후** 실수령 메소 |
| `파티원수` | Integer (1~6) | ✅ | 분배할 파티 인원 수 |
| `카르마가위` | Integer | ❌ | 카르마의 가위 구매 비용 (없으면 생략) |

### 사용 예시

```
/분배 아이템명:이계의반지 판매금:50000000 파티원수:6 카르마가위:1500000
```

---

## 계산 로직

```
1) 판매금 − 카르마의 가위                = 정산 금액
2) 정산 금액 ÷ 파티원수 (버림)            = 1인당 몫
3) 1인당 몫 → 구간별 택배 수수료 산출
4) 1인당 몫 − 택배 수수료                 = 최종 수령액
```

### 택배 수수료 = 기본료 10,000 메소 + 송금 구간별 수수료율

| 1인당 몫 (송금 금액) | 수수료율 |
|---------------------|---------|
| 10만 메소 미만 | 기본료만 |
| 10만 메소 이상 | 0.80% |
| 100만 메소 이상 | 1.80% |
| 500만 메소 이상 | 3.00% |
| 1,000만 메소 이상 | 4.00% |
| 2,500만 메소 이상 | 5.00% |
| 1억 메소 이상 | 6.00% |

> 수수료 계산식: `10,000 + (1인당 몫 × 해당 구간 수수료율)`

## 출력 예시 (이계의반지 5,000만, 6명, 카르마 150만)

```
🍁 [ 이계의반지 ] 판매 수익금 분배
색상: 레드 #E74C3C

수수료 제외 48,500,000메소 정산 · 6명 분배

📊 정산 내역
판매금 (거래소 수수료 제외 후) : 50,000,000메소
카르마의 가위 : -1,500,000메소
━━━━━━━━━━━━━━━━━━━
정산 금액 : 48,500,000메소
÷ 6명 → 1인당 몫 : 8,083,333메소
택배 수수료 (기본료 10,000 + 3%) : -252,499메소
━━━━━━━━━━━━━━━━━━━

💰 최종 수령액 (택배 발송 금액)
1인당 7,830,834 메소

(나머지 2메소 버림 처리)

📦 분배 내역
• 파티원 1 : 7,830,834메소
• 파티원 2 : 7,830,834메소
... (6명 전부)

(푸터) 택배 기본료 10,000메소 + 송금 구간별 수수료율 적용
```

## 검증된 테스트 케이스

| 아이템 | 판매금 | 카르마 | 인원 | 1인당 몫 | 택배 수수료 | 최종 수령액 |
|-------|--------|--------|------|---------|-----------|-----------|
| 주문서 | 1,000,000 | 0 | 4 | 250,000 | 12,000 (0.8%) | **238,000** |

| 창천의명궁 | 200,000,000 | 2,000,000 | 6 | 33,000,000 | 1,660,000 (5%) | **31,340,000** |
| 작은 아이템 | 50,000 | 0 | 1 | 50,000 | 10,000 (기본만) | **40,000** |

## 배포 가이드 (요약)

1. 디스코드 개발자 포털 → Application 생성 → Bot 토큰 발급
2. OAuth2 → URL Generator → SCOPES: `bot`, `applications.commands` / PERMISSIONS: `Send Messages`, `Embed Links` → 서버 초대
3. GitHub 레포에 이 폴더 푸시 (`.env` 절대 X)
4. Railway → New Project → Deploy from GitHub repo → 레포 선택
5. Variables 탭 → `DISCORD_BOT_TOKEN` 등록
6. Deployments 로그에 `로그인 성공 ... 슬래시 명령어 1개 동기화 완료` 확인
